# New Contributor Onboarding (S-BUILD Phase 5)

## Prerequisites
- Node 18+
- Git
- VS Code + ESLint recommended

## First 15 Minutes
1. git clone https://github.com/DealAppSeo/repid-engine
2. cd repid-engine && npm install
3. npm run build (0 TS errors expected)
4. npm test (1289+ tests passing)
5. Read CONTRIBUTING.md + docs/ARCHITECTURE.md + docs/SECURITY.md

## Your First PR
- Pick a "good-first-issue" from GitHub
- Branch from main
- Make small, focused change + test
- Open PR with description referencing the spec/sprint

## Good First Issues
- Look for labels: good-first-issue, documentation, test
- Examples: improve a signal tooltip, add a test case for a new provider, update an outdated comment

## Architecture
See docs/ARCHITECTURE.md (5 layers) and SCHEMA_TRUTH_MAP.md (living schema truth).
