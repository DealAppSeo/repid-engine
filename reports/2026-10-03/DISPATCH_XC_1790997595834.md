Both vibe-coders (who get burned on broken PRs) and senior engineers (who waste review time on false confidence) feel this daily. It destroys trust in agent-generated code.

**Product:** A zero-trust "receipt engine" — a GitHub Action (`trustshell/receipt`) that parses an agent's PR claims, cross-checks them against GitHub's immutable evidence (check runs, job logs, workflow conclusions, artifacts), and posts a single canonical comment with machine-verified verdicts (`[V]`, `[R]`, `[FAILED]`, `NOT_CHECKED`). One-line pitch: **"AI says it ran the tests. Here's the receipt from GitHub itself."**
